# 10. VUE PUBLIC WEB SCREEN SPECIFICATION

**Document ID:** BN-DOC-010  
**Ref:** Master PO Execution Order BN-GAMEEX-MASTER-001 (Article 9 & 10)  

---

## 1. Public Screens Overview
1. **Home Screen (`/`)**:
   - Hero banner with headline "Find gaming goods from verified sellers."
   - Game-first search combo (Game dropdown, Platform selector, Keyword input)
   - Pre-cleared game carousel with live compliance badges
   - Trending verified listings grid with unit prices
   - Evidence-based buyer protection explanations
2. **Game Catalog Page (`/games/{slug}`)**:
   - Platform & server tab filter
   - Product type selector (GAME_ITEM, OFFICIAL_GIFT_CODE)
   - Real-time unit price comparison table
3. **Listing Detail Page (`/listings/{id}`)**:
   - Verified seller badge & rating summary (rating count, completion rate)
   - ETA and in-game delivery method instructions
   - Fee transparency breakdown widget
   - Interactive quantity counter & quote generator
4. **Order Management Screen (`/my/orders/{id}`)**:
   - Live order lifecycle progress timeline
   - Delivery evidence preview (video/image with SHA256 verification tag)
   - Action buttons: "Confirm Receipt" or "Open Dispute"
